# Développement — Niko Live Commander

Référence web : https://github.com/GoogleChrome/modern-web-guidance

Préserver le fonctionnement local-first, les enregistrements, la navigation tactile, le timer et les exports. Ne jamais simuler un accès à TikTok LIVE, une prise de contrôle d'OBS distant ou l'existence d'un flux audio. Préserver les permissions utilisateurs et l'absence de clés publiques.

Application sans framework ni dépendance. Favoriser API natives, formulaires accessibles, focus visible et compatibilité Safari iOS / Android. Ne pas lancer de campagnes de tests sans demande explicite ; distinguer modifications, déploiement et fonctionnement vérifié.
